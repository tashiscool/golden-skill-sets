# Expected Output Shape

## Issue Context

- Summarize issue body, comments, labels, reporter activity, and prior triage notes.
- Note relevant code or docs inspected.

## Recommendation

- Recommend category and state with reasoning.
- For bugs, report reproduction result or why reproduction is blocked.
- Identify missing acceptance criteria or reporter questions.

## Proposed Mutations

- List exact labels, comments, or state transitions that would be applied.
- Include the AI triage disclaimer for any proposed issue comment.

## Human Gate

- Ask for confirmation before applying mutations unless the user has already explicitly confirmed the exact transition.
