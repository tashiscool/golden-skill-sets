# Expected Output Shape

## Requirements

- Ask what task/domain the skill covers.
- Ask what use cases should trigger it.
- Ask whether scripts, references, or examples are needed.

## Draft Shape

- `SKILL.md` with frontmatter, concise trigger-rich description, and workflow.
- Optional reference files for long or rare details.
- Optional scripts only for deterministic repeated operations.

## Validation

- Check description trigger language.
- Check examples against the intended use cases.
- Confirm the skill is not too broad.
- Provide a review checklist before treating it as ready.
