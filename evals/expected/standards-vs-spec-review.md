# Expected Output Shape

## Standards

- Cite the standards sources read.
- List findings that violate documented standards.
- Distinguish hard violations from judgment calls.

## Spec

- Cite the PRD/spec source.
- List missing, partial, wrong, or scope-creep behavior.
- Quote or reference the relevant spec requirement for each finding.

## Limitations

- If no spec exists, say so and skip spec findings.
- Mention test gaps or residual risk even if no issues are found.

## Summary

- Count findings per axis.
- Name the worst issue, if any.
