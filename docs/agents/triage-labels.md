# Triage Labels

The workflow skills speak in terms of five canonical triage roles. This file maps those roles to the label strings used in this repo's issue tracker.

| Canonical Role | Label In Tracker | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Maintainer needs to evaluate this issue |
| `needs-info` | `needs-info` | Waiting on reporter for more information |
| `ready-for-agent` | `ready-for-agent` | Fully specified and ready for an agent |
| `ready-for-human` | `ready-for-human` | Requires human implementation or judgment |
| `wontfix` | `wontfix` | Will not be actioned |

Every triaged issue should have exactly one state role. If state labels conflict, stop and ask before changing labels.
