# Domain Docs

This repo is configured as a single-context repo for the engineering workflow skills.

## Before Exploring

Read these if present:

- `CONTEXT.md` at the repo root
- ADRs under `docs/adr/`
- Relevant specialist files under `extended-agents/`

If a file does not exist, proceed silently. `grill-with-docs` may create domain vocabulary or ADRs lazily when a real term or decision is resolved.

## Vocabulary

Use the project's established names for agent roles, skill categories, and workflow states. If a term is ambiguous or overloaded, ask or run a `grill-with-docs` session rather than inventing a synonym.

## ADR Conflicts

If a proposed change contradicts an existing ADR, surface the conflict explicitly and keep the architecture change advisory until the user approves reopening that decision.
